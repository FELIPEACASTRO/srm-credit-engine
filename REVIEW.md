# REVIEW — Anexo A (`settlement.controller.ts`)

**Veredito: REJEITADO — não mergear.** E como o Anexo B mostra que este código **já está em produção há duas semanas**, a primeira ação não é corrigir o PR: é **conter o incidente** (ver [`docs/incident/postmortem-anexo-b.md`](docs/incident/postmortem-anexo-b.md)).

**Premissas desta revisão** (mudam a ordenação, então ficam explícitas): PostgreSQL com node-postgres; Express 4 (nota no defeito 8 sobre Express 5); API acessível **apenas na rede interna da mesa**. Se a API estiver exposta, os defeitos 4 e 10 sobem para 1º e 2º.

**Critério de ordenação — por impacto de negócio, não por gravidade técnica abstrata:** dinheiro errado em operação normal > duplicação de pagamento > o que exige um atacante > operacional. Um SQL injection exige alguém explorá-lo; o bug de unidade erra o preço em **100% das requisições legítimas**, silenciosamente, com `200 OK`.

## Prevenção sistêmica (por que isso passou, e que gate barraria cada item)

"Gerado por IA e aprovado às pressas numa sexta" não é a causa raiz — é o sintoma de **nenhum gate automatizado** entre o gerado e a produção:

- **Golden cases no CI** barram o nº 1 no primeiro commit (30 s de execução).
- **Teste de replay + UNIQUE no banco** barram o nº 2 — a constraint vale até contra acesso direto.
- **Grep/SAST de SQL interpolado** barra o nº 4 (uma linha de pipeline).
- **Métrica `settlement_discount_ratio`** pegaria o nº 1 na primeira liquidação real (PV/face do C1 = 0,0233 gritaria num dashboard).
- **Conciliação diária** (duplicatas = 0) pegaria o nº 2 em horas, não semanas.
- **Checklist de PR para código no caminho do dinheiro** (decimal de string, arredondamento explícito, SQL parametrizado, goldens intocados).

Custo total: minutos por PR — o oposto da burocracia que trava o time. Este repositório implementa cada um desses gates ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)); a arquitetura daqui é o negativo deste review: **cada defeito acima tem um mecanismo nomeado que o torna impossível ou detectável em minutos.**
